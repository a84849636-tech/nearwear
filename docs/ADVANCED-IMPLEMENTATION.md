# NEARWEAR 고도화 구현·검증 기록

## 현재 상태 — 원본 사진 적용 전 부분 구현

기능과 화면 구조는 이 저장소에 구현되어 있습니다. **전달된 PNG는 대화에서 시각적으로 확인했지만, 작업 환경에는 다운로드 가능한 PNG 파일·경로가 제공되지 않았습니다.** 대용량 ZIP은 전송 도구의 32MiB 한도로 내려받지 못했습니다. 현재 `public/figma/assets.json`은 비어 있으며, 사진 영역은 `원본 이미지 준비 중`으로 표시합니다. 이전 버전 사진·생성 이미지·유사 사진을 대신 사용하지 않았습니다.

따라서 사진 포함 디자인의 1:1 일치, 원본 이미지 비교 검증, 발표 가능한 완성 상태는 **미완료**입니다. 실제 공개 미리보기 배포 역시 아래 기록이 있을 때만 완료로 판단해야 합니다. 로컬 서버 실행·HTML 산출물 생성은 Vercel 배포가 아닙니다.

## 주요 파일

- `src/advanced-data.js`: 전달 화면의 매장·상품·결과 문구·갤러리/스토리 개수·원본 자산 키.
- `src/advanced-domain.js`: 중복 없는 취향 세션, 점수, 필터·핀, 예약·가입 검증.
- `src/advanced-app.js`: 해시 라우팅, 화면, 저장, 시연 로그인·예약·배송, 원통·지도 제스처.
- `src/advanced.css`: 430px 레이아웃, 24px 여백, 화면별 밝고 어두운 스타일, 작은 화면·reduced motion.
- `public/figma/assets.json`: 원본 이미지 연결 전 비어 있음. 경로 규약은 FIGMA-ASSETS.md 참고.
- `tests/advanced-domain.test.mjs`, `tests/advanced-data.test.mjs`: Node 테스트.
- `tests/browser_smoke.py`: 실제 Chromium 사용자 흐름과 레이아웃 검증.
- `scripts/standalone-preview.mjs`: 서버 없이 전달할 HTML 산출물 생성. 현재 관리형 Chromium은 file:// 열기를 차단하므로 이 산출물 자체는 별도 HTTP 서버로 검증함.
- `vercel.json`: 명시적 빌드·출력 경로 설정. 추가만으로 배포되지 않음.

## 실행과 검증

Node.js 20 이상. 외부 npm 의존성 없음.

```sh
cd /workspace/nearwear
npm run dev
# 다른 터미널
npm test
python tests/browser_smoke.py
npm run build
npm run assets:check
node scripts/standalone-preview.mjs
```

- `npm test`: 10개 테스트 통과.
- `python tests/browser_smoke.py`: 실행 결과는 `/workspace/nearwear-artifacts/browser-results.json`. 16개 시나리오 통과, 브라우저 예외 0개. PNG 스크린샷은 해당 실행 산출물을 확인.
- 430×932 스크린샷을 원본의 보이는 구조·간격과 수동 대조. 상품 헤더 사진 높이278, 좌우24, 흰 카드 시작y331 등 맞춤. 로그인 세로 간격 보정. **원본 이미지 파일이 없어 전체 픽셀 차이 비교는 수행 불가.**
- 320·375·430·1440px 가로 넘침 검사. 430px에서 상품 사진 x=24, 너비382 검사.
- `npm run assets:check`: 현재 누락 상태를 이유로 종료 코드1이 정상. 이것은 성공 검사가 아니라 이미지 미완료 상태를 드러내는 점검.
- `npm run build`: 구문·정적 파일·자산 manifest 경로 검사. 이미지 개수가0임을 출력하며 사진 완성을 보증하지 않음.
- 원본 PNG에 포함된 iOS 상태바·기기 테두리는 브라우저 자체 UI와 혼동되지 않도록 웹 콘텐츠로 복제하지 않음.

## 시연 방법

1. 서버를 실행하고 브라우저에서 `http://localhost:4173/`를 열면 START부터 시작.
2. 이미지 없이도 LIKE/SKIP 입력·결과·지도 핀·상세·예약 경로는 작동함. **사진이 필요한 발표의 완성본으로 사용하기에는 미완성.**
3. 예약에서 시연용 이메일(예: demo@example.com)과 아무 시연용 비밀번호를 입력. 실제 인증 아님. 입력 원문·비밀번호는 저장하지 않고 이메일 해시를 사용자별 로컬 시연 ID로 사용.
4. 예약 날짜는 현재 한국 날짜 기준 미래의 영업일을 선택. 재고 잠금은 브라우저 내 시연 범위이며 서버 동시성 보장은 없음.
5. `?demo=1#/map`으로 열면 첫 한 번 OTUVINTAGE·RYOHE·OTOTO를 저장 목록에 넣어 업로드/저장 화면을 시연 가능. 취향 투표나 구매·예약 완료는 미리 만들어 넣지 않음.
6. 게스트의 매장·상품·최근 기록은 시연 로그인 계정으로 중복 없이 병합 후 게스트 목록을 비움. 기존 계정 기록 보존. 다른 계정 기록을 보여주지 않음.
7. 기존 nw-* 키는 삭제하거나 변경하지 않고 새 nw3-* 키를 사용.

## 미리보기와 운영 사이트

현재 로컬 서버는 `HOST=0.0.0.0 npm run dev`로 4173 포트에서 실행. 별도 다운로드용 HTML은 `/workspace/nearwear-artifacts/NEARWEAR-preview.html`. 관리형 환경의 file:// 정책 차단 때문에 사용자 PC에서 직접 열기는 별도로 검증되지 않았고, 같은 HTML은 HTTP 서버에서 초기 진입·시연 로그인까지 검증함.

Vercel 인증·프로젝트 바인딩은 현재 환경에서 발견되지 않음. 토큰 부재만으로 GitHub 인증 문제라고 판단하지 않음. 운영 사이트·프로덕션 배포 명령은 실행하지 않음. Vercel이 연결된 환경에서 이 브랜치를 Preview로 배포할 때는 `vercel deploy`를 사용하고 `--prod`를 사용하지 않음. 운영 환경 업데이트와 Preview 배포를 구분해야 함.
