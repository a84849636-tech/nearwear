# NEARWEAR 고도화 — 구현 검토본

기존 NEARWEAR 저장소의 발표용 핵심 흐름을 구현한 별도 브랜치입니다. **화면·기능은 구현했지만 원본 사진 파일이 연결되지 않아 디자인 완성본은 아닙니다.** 대화에 표시된 PNG로 화면을 분석했으나, 현재 실행 환경에 사용할 수 있는 원본 파일은 없습니다. 사진 영역에는 `원본 이미지 준비 중`을 표시하며 구버전 사진을 대신 사용하지 않았습니다.

- 브랜치: `feat/nearwear-advanced-figma`
- 원본 기준: 사용자가 전달한 01~24 PNG와 수정 확정 사항, Advanced PRD·PROMPT
- [Vercel 브랜치 미리보기](https://nearwear-git-feat-nearwear-advanced-figma-hb-9c17.vercel.app/) — GitHub에서 생성된 주소 확인. 현재 클라우드 프록시가 접근을 차단하여 원격 실행은 미검증.
- 기존 운영 사이트에 병합·운영 배포하지 않았습니다.

## 실행

Node.js 20 이상. npm 의존성 설치·API 키·데이터베이스 없이 실행합니다.

```sh
npm run dev
```

브라우저에서 `http://localhost:4173/`를 열면 START부터 시작합니다. 모바일 콘텐츠는 430px·좌우24px 기준이며 데스크톱에서는 가운데 표시됩니다.

START → 성별 선택 → 12장 취향 선택 → 9종 결과 → 지도 → 매장 미리보기 → 매장 상세 → 상품 → 시연 로그인 → 방문예약을 연결했습니다. 배송·스토리·탐색·저장·회원가입·MY·세 종류의 퍼즐·설정 목록도 포함합니다.

`http://localhost:4173/?demo=1#/map`으로 처음 열면 화면에 제공된 OTUVINTAGE·RYOHE·OTOTO를 저장 목록에 넣어 STORIES·SAVED를 시연할 수 있습니다. 실제 투표·구매·예약을 미리 완료한 것으로 꾸미지 않습니다.

## 검증

```sh
npm test                         # Node 테스트 10개
python tests/browser_smoke.py     # Python Playwright + Chromium 필요; 시나리오16개
npm run build                    # dist 출력
npm run assets:check              # 미연결 원본 이미지가 있으면 종료코드1
npm run preview                  # 빌드 결과 서버; dev와 같은 포트이므로 둘 중 하나 실행
node scripts/standalone-preview.mjs  # 검토용 독립 HTML 생성
```

현재 Node 테스트10개, Chromium 시나리오16개 통과. 430px·24px 여백, 320/375/430/1440px 가로 넘침, 중복 클릭, 새로고침, 게스트 저장 병합, 예약·배송 폼과 가입 복귀를 검사했습니다. 원본 사진의 시각 비교는 미완료입니다.

## 시연 범위

실제 인증·결제·재고·배송·매장 예약 서버는 연결하지 않았습니다. 로그인과 신청은 시연용이며 화면에 표시합니다. 실사용 이메일·비밀번호·주소를 입력하지 마세요. 비밀번호·이메일 원문·배송 주소·카드정보는 저장하지 않습니다. 위치 권한을 확인할 수 있지만 검증된 매장 좌표와 실제 지도는 없습니다. 반경 필터는 좌표 없이 거리를 만들어내지 않습니다.

7개 상세 매장과 전달된 상품 상세7개만 연결합니다. 나머지 피드·상품·설정 상세를 임의로 만들지 않고 준비 중으로 안내합니다. 기존 nw-* 저장 키는 보존하고 새 nw3-* 키를 사용합니다.

자세한 화면별 완료·부분·미완료 현황과 변경 파일은 [구현 기록](docs/ADVANCED-IMPLEMENTATION.md), 원본 파일 연결은 [자산 연결 규약](docs/FIGMA-ASSETS.md)을 참고하세요. 이전 버전 README·코드는 기존 기준 커밋 `353133c`에 보존되어 있습니다.
