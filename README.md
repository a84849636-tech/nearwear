# NEARWEAR 모바일 웹 MVP

제공된 `NEARWEAR_PRD.md`, `NEARWEAR_PROMPT.md`와 공유된 12화면 기획에 따라 제작한 클릭 가능한 프런트엔드 프로토타입입니다. 문서 원본은 프로젝트에 함께 보관했습니다.

## 실행

Node.js 18 이상에서 이 폴더를 열고 `node server.cjs`를 실행합니다. http://127.0.0.1:4174 에 접속하세요. 추가 패키지 설치는 필요하지 않습니다. npm이 설치되어 있다면 `npm start`도 가능합니다.

별도 서버 없이 확인하려면 함께 제공된 `nearwear.html`을 브라우저에서 열 수 있습니다.

## 화면과 기능

1. 브랜드 시작 화면
2. 취향 사진 선택: 버튼 또는 좌우 스와이프
3. 취향 결과와 탐색 동네 선택
4. 지역·스타일 탐색 설정
5. 매칭 점수를 표시한 예시 지도
6. 지도 핀의 매장 미리보기
7. 매장 분위기·정보·저장
8. 상품 피드와 카테고리 필터
9. 상품 사진·가격·실측·컨디션·저장
10. 예약 선택 또는 추천 상품 탐색
11. 3시간 데모 예약·카운트다운·방문 안내
12. MY: 취향, 예약 확인·취소, 저장한 매장·상품

상단의 '12화면 보드'로 전체 화면을 비교하고 '직접 사용하기'로 흐름을 체험합니다.

## 파일

- `index.html`: 문서와 화면 컨테이너
- `styles.css`: 차콜·라임 테마, 반응형 레이아웃, 내장 사진
- `data.js`: 가상 매장 7곳, 매장별로 연결된 상품 12개, 취향·재고 상태
- `app.js`: 12화면, 탐색·찜·예약 상태, 카운트다운과 만료 이력
- `server.cjs`: 로컬 미리보기 서버
- `test.cjs`: 예약 상태 전이와 저장 복원 등의 검증
- `vercel.json`: 정적 배포 설정
- `VERIFICATION.md`: PRD 완료 조건과 검수 결과

## 현재 구현 범위

- 매장, 재고, 매칭 점수와 지도는 데모입니다. 실제 예약이나 결제가 발생하지 않습니다.
- 취향·찜·예약은 현재 브라우저 localStorage에 저장합니다. 계정 간 동기화는 없습니다.
- 예약은 한 번에 한 상품, 확정 후 3시간입니다. 취소하거나 시간이 지나면 보관이 해제되고 `CANCELLED` 또는 `EXPIRED` 이력이 남습니다. 품절·다른 예약 중인 상품은 예약할 수 없습니다.
- '지역 전체'를 선택하면 스타일 단독, 스타일을 모두 해제하면 위치 단독 탐색이 됩니다. 지역은 매장 목록을 제한하고 스타일은 매칭 점수와 추천을 바꿉니다.
- 위치 사용 토글은 성수 데모 위치를 설정합니다. 실제 GPS 권한은 요청하지 않습니다.
- 길찾기는 가상 매장 주소 대신 선택 지역의 네이버 지도 검색을 엽니다.
- 사진은 AI 생성 콘셉트 이미지이며 일부 샘플 상품은 같은 사진을 공유합니다. 상품의 두 번째 이미지는 상세 확대이고 반다나는 사진 준비 중 영역입니다.
- Google Fonts 연결이 없으면 시스템 글꼴을 사용합니다. 외부 JavaScript 라이브러리는 사용하지 않습니다.
- 이전 초안과 구분해 localStorage의 `nearwear-v2`에 저장합니다. 로그인·실제 재고·결제·지도 API는 MVP 범위에서 제외했습니다.

## 검증

`node --check app.js`로 JavaScript 구문을 검사하고 `node test.cjs`로 상태 테스트를 실행합니다. npm이 있다면 `npm run check`, `npm test`도 가능합니다. 테스트는 별도 가상 저장소를 사용하며 브라우저의 데이터를 바꾸지 않습니다.

예약 만료를 직접 검수하려면 `http://127.0.0.1:4174/?dev=1`에 접속한 후 상품을 예약하세요. 예약 화면의 '개발 검수: 5초 후 만료'를 누르면 해당 데모 예약이 5초 후 만료됩니다. 일반 URL에서는 이 버튼을 표시하지 않습니다.

## Vercel 배포 준비

`index.html`과 정적 파일이 있는 이 프로젝트 폴더를 배포 루트로 사용합니다. 프레임워크는 Other, 빌드 명령은 비움, 출력 디렉터리는 루트(`.`)로 설정하는 정적 웹 구조입니다. `server.cjs`는 로컬 실행용이며 호스팅에는 필요하지 않습니다.

배포 가능한 파일을 준비한 상태입니다. 실제 Vercel 배포는 수행하지 않았습니다.

## 2026-10-21 Figma 고도화 화면 적용

기본 진입점(index.html)을 Figma NEARWEAR (고도화) 01~24 및 파생 화면 132개의 웹 화면으로 변경했습니다. 원본 이미지/SVG 607개는 assets/figma에 저장했습니다. 실행은 기존과 같이 node server.cjs이며, 전체 화면 목록은 http://127.0.0.1:4174/#screens 에서 확인할 수 있습니다.

기존 12화면 데모와 nearwear-v2 저장 데이터는 legacy.html에서 유지합니다. 고도화 화면은 별도 nearwear-v3 상태를 사용합니다. 인증, 실시간 지도, 실제 결제와 배송은 연결되지 않았습니다. 이미지별 취향 분류 데이터가 없어 결과는 Figma 9번째 시연 카드를 사용합니다. npm run check와 npm test는 새 화면 자산 검증 및 기존 예약 테스트를 포함합니다.
